# 期末命题（final-exam-authoring-skill）

一套高校期末命题的标准作业流程（SOP）skill，给 AI Agent 用，也可以人直接照做。
覆盖两类考核：**试卷类**（闭卷笔试 / 上机考试）与**项目作业类**（非笔试考核）。

## 它解决什么问题

命题最容易翻车的地方不是出题，而是**源头没对齐**：

- 卷面各目标分值和大纲给的期末分值对不上；
- 组卷策略明细表的题型抬头和试卷大题名各写各的；
- 去年现做的组卷策略表今年做不出来（合并单元格、页面设置全丢了）；
- 项目作业写成了小组项目，或者冒出"答辩""提交视频"这种本校不要求的表述。

这份 skill 把这些做成固定流程：**源头清单 → 目标分值校验 → 出卷 / 出任务书 → 逐项校验 → 落位汇报**。

## 核心约定

| 环节 | 依据 |
|---|---|
| 各目标分值 | 教学大纲「课程考核」章最后一张表的**"期末考核"列**，小计必须 = 100 |
| 每目标覆盖内容 | 教学大纲「课程教学目标」表的课程内容原文 |
| 客观题题干与答案 | 学习手册原文照录，不改字、不调语序 |
| 命题词汇范围 | 教案里讲过的内容 |
| 版式与表格结构 | 学校试卷袋里的历史卷子与组卷策略表 |

## 两类考核的成品

- **试卷类**：A 卷、B 卷、A 答案、B 答案、命题审查表、组卷策略明细表（只出 docx / xls）
- **项目作业类**：项目作业任务书（指导书）、非笔试类命题审查表

## 用法

把这个目录放进 Agent 的 skills 目录（如 `~/.qwenpaw/skills/` 或工作区 `skills/`），
Agent 在听到"期末命题 / 出卷子 / A B 卷 / 组卷策略 / 项目作业任务书"时会自动加载。

人用的话，直接读 `SKILL.md`：六章 = 源头清单、目标分值校验、试卷类流程、项目作业类流程、模板库、踩坑表 + 验收清单。

## 仓库内容

```
final-exam-authoring-skill/
├─ SKILL.md                      全套 SOP（六章：源头清单／目标分值校验／试卷类／项目作业类／模板库／坑表+验收）
├─ docs/
│  └─ 组卷策略模板结构说明.md      组卷策略明细表的完整骨架，没有 xls 母版也能 1:1 复刻
└─ assets/
   ├─ 参考图样例_功能结构图_A.svg  黑白纯线条，可直接打印
   ├─ 参考图样例_功能结构图_B.svg
   ├─ 参考图样例_ER图_A.svg
   └─ 参考图样例_ER图_B.svg
```

**组卷策略表**在多数学校只有纸质/校内电子版，仓库因此给出结构说明而非文件：
A4 横向、17 行 × 26 列、61 处合并单元格、每个题型块 4 列（容易1/较易2/较难3/难4），
列宽、逐行内容、填数与自查规则全部写在 `docs/组卷策略模板结构说明.md` 里，照着建表即可。

## 说明

- 仓库里只放方法与黑白线图样例，**不含任何学校的真实试卷、答案、审查表、签字与印章**。
  那类模板属于校内材料，请自行保管，不要提交到公开仓库。
- `SKILL.md` 中的本校路径均已脱敏为占位符：`{课程材料目录}`、`{教学材料目录}`、
  `{成品目录}`、`{试卷袋参考目录}`、`{工作目录}`、`{skill目录}`、`{学校名称}`、
  `{指导教师姓名}`，按自己环境替换即可。
- 学校名称、课程与目标分值是示例，换学校/换课程时按第零章的"源头清单"逐项替换。
