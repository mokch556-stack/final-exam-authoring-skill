# 组卷策略明细表 · 结构说明（空白母版通用）

> 用途：在没有原始 xls 母版的情况下，也能复刻出学校要求的《期末组卷策略明细表》。
> 依据：某校试卷袋中的历史组卷策略表（5 题型示例：单选题 / 判断题 / 简答题 / 综合计算题 / 案例分析题，22 题 100 分）反推出的表格骨架。
> 复刻时按本文档逐项建表，版面、合并、列宽都对得上，打印出来就是同一张表。

---

## 一、页面设置

| 项目 | 值 |
|---|---|
| 纸张 | A4，**横向** |
| 缩放 | 调整为「1 页宽 × N 页高」（`FitToPagesWide=1`）；N 一般取 1，题型多于 5 类时取 2 |
| 打印标题行 | 建议设 `$1:$5`（标题行 + 题型头部 + 难度档），跨页时每页重复表头 |
| 页边距 | 常规（上 1.9 / 下 1.9 / 左 1.8 / 右 1.8，可按打印效果微调） |
| 全表字体 | 宋体，正文小五～五号，标题五号加粗 |

## 二、总体尺寸

- 数据区 **A1:Z17**：17 行 × 26 列（A–Z）。
- Y、Z 两列为空白缓冲（列宽 8.4），打印区不含。
- **合并单元格 61 处**，建表时必须一次性做完合并，否则后续填数容易错位。

## 三、列骨架（题型块 = 4 列）

| 列 | 归属 |
|---|---|
| A | 课程内容清单（跨整行，宽度 33.9，全表最宽） |
| B | 目标编号（1/2/3/4…），窄列 2.8 |
| C–F | **题型块 1**：容易 1 / 较易 2 / 较难 3 / 难 4 |
| G–J | **题型块 2**：同上四档 |
| K–N | **题型块 3**：同上四档 |
| O–R | **题型块 4**：同上四档 |
| S–V | **题型块 5**：同上四档 |
| W | 合计（每行小计 / 总计） |
| X | 难度占比（百分比） |
| Y、Z | 空白缓冲 |

> **加题型块**：整块 4 列插在 W 列之前，同步把 W/X 的合计与占比公式向右移，难度档表头（容易1/较易2/较难3/难4）随块复制。题型数决定 A4 横向能放几类——5 类 22 列刚好一页宽，6 类压到 26 列（A–Z）仍在 1 页宽内。

## 六、填数规则（五条）

1. **第 4 行「分值」填每题的题分**，不是题型总分；某题型总分 = 该题型题数 × 题分。
2. **第 7–10 行填题数**，一格一题；一个目标在某一难度上没题就填 0，不留空。
3. **第 11 行 = 各块题数之和**（可用 `SUM`），**第 12 行 = 各块题分×题数之和**；两行合计必须分别等于全校要求的题量与 100 分。
4. **第 13–16 行 = 难度数量汇总**，按行把该难度在全部题型块的题数相加；四行合计 = 第 11 行合计。
5. **X 列占比**：母版残留 `14% / 40% / 31% / 15%` 是历史值，与新表不符，**必须重算**。口径只准选一种并在表下注明：
   - 数量占比 = 该难度题数 ÷ 总题数（如 5/11/8/2 ÷ 26 = 19% / 42% / 31% / 8%）
   - 分数占比 = 该难度题分之和 ÷ 100（同例为 8% / 20% / 39% / 33%）
   两种口径得出的数完全不同，混写就会出现「表里说 19%，卷面算出来 8%」的矛盾。
